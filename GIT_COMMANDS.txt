GIT COMMANDS TO DEPLOY TO GITHUB
==================================

STEP 1: Install Git (if not installed)
--------------------------------------
Download from: https://git-scm.com/download/win
Install and restart PowerShell after installation.

STEP 2: Initialize and commit
------------------------------
git init
git add .
git commit -m "Initial commit: UNI Events platform"

STEP 3: Create repository on GitHub
------------------------------------
1. Go to https://github.com/new
2. Create a new repository (don't initialize with README)
3. Copy the repository URL

STEP 4: Connect and push
------------------------
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main

NOTE: Replace YOUR_USERNAME and YOUR_REPO_NAME with your actual values.
